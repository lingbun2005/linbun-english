Cách 1: Netlify Drop (Nhanh 15 giây)
  1. Bấm nút "⬇️ Tải file index.html" ngay trên thanh công cụ.
  2. Truy cập app.netlify.com/drop và kéo thả tệp index.html vào.
  3. Nhận ngay đường dẫn https://linbun-cua-ban.netlify.app để học trên mọi thiết bị!
Cách 2: GitHub Pages (Lưu trữ vĩnh viễn)

Tải index.html lên một Repository công khai trên GitHub → vào Settings → Pages → Branch: main → Save để nhận link web cố định trọn đời.
